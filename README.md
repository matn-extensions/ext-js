# JavaScript & TypeScript Language Server

Real-time JS/TS diagnostics, IntelliSense, hover docs via typescript-language-server

## Details
- **Identifier**: `matn.ext.js`
- **Version**: `1.0.0`
- **Category**: `languages`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **JavaScript & TypeScript Language Server**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-js
```
